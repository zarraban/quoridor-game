# ♟️ QUORIDOR: TACTICAL DUEL

> **Навчально-дослідний проєкт: розробка покрокової настільної стратегії на полі $9 \times 9$ із реалізацією контрагентного штучного інтелекту (Minimax).**

---

### 📌 1. Постановка задачі та правила гри

Ігрове середовище моделюється як антагоністичне змагання двох агентів на дискретному незваженому графі розміром $9 \times 9$:

| Параметр | Характеристика |
| :--- | :--- |
| **Ігрове поле** | Сітка $9 \times 9$ клітинок (81 вершина графу) |
| **Мета гри** | Першим перемістити свого пішака до будь-якої клітинки протилежного краю дошки |
| **Ресурсне обмеження** | По **10 стінок** у кожного гравця на партію |
| **Допустимі дії за такт** | **Крок фігуркою** на суміжну вільну клітинку (або стрибок) **АБО** **встановлення стінки** (перекриває 2 суміжних ребра) |
| **Критичне правило (No-block)** | **Заборонено повне блокування**: у графі завжди має існувати хоча б один шлях від поточної позиції кожного гравця до його фінішу |

---

### 🧠 2. Контрагентний штучний інтелект: Алгоритм Minimax

Супротивник реалізований як інтелектуальний агент у покроковій грі з нульовою сумою та повною інформацією. Для вибору оптимального ходу використовується класичний теоретико-ігровий алгоритм **Minimax**:

* **MAX (ШІ)** — прагне обрати дію, яка максимізує кінцеву оцінку стану гри.
* **MIN (Людина)** — моделюється як раціональний опонент, який намагається мінімізувати вигоду ШІ.

```
                   [Поточний стан (MAX)]
                   /                   \
        [Крок фігуркою]             [Встановлення стінки]
           /        \                   /          \
      (Хід MIN)  (Хід MIN)         (Хід MIN)    (Хід MIN)
           ↓          ↓                 ↓            ↓
      [Score = +3] [Score = +1]    [Score = +6]  [Score = -2]
```

---

### 📐 3. Евристична оціночна функція (Evaluation Function)

Оскільки фактор розгалуження в Quoridor надзвичайно високий (до 130 варіантів дій за хід), повний перебір дерева гри до фіналу є обчислювально неможливим. Пошук обмежено фіксованою глибиною, а листові вузли дерева оцінюються евристичною функцією:

$$\text{Score} = (\text{dist}_{\text{Player}} - \text{dist}_{\text{AI}}) + \omega \cdot (\text{walls}_{\text{AI}} - \text{walls}_{\text{Player}})$$

* **$\text{dist}$ (найкоротший шлях)** — розраховується алгоритмом **BFS (Breadth-First Search)** із часовою складністю $O(V + E)$ в обхід усіх встановлених перешкод.
* **Різниця дистанцій** — основа оцінки: чим довший маршрут супротивника і чим коротший власний шлях до мети, тим вигідніша позиція.
* **Запас стінок ($\text{walls}$)** — ресурсний фактор із ваговим коефіцієнтом $\omega$, що спонукає бота економити перегородки для фінальної стадії гри.

---

### ⚡ 4. Оптимізації швидкодії та звуження дерева пошуку

Для забезпечення прийнятного часу відповіді агента в реальному часі застосовано комплекс методів:

1. **Альфа-бета відсікання ($\alpha$-$\beta$ Pruning)**:
   * Зберігаються динамічні межі $\alpha$ (найкращий результат для MAX) та $\beta$ (найкращий для MIN).
   * Якщо знайдено гілку, яка гарантовано гірша за вже досліджену альтернативу, вона негайно відсікається, скорочуючи кількість розрахунків у найкращому випадку до $O(b^{d/2})$.
2. **Евристична селекція стінок (Move Filtering)**:
   * ШІ не аналізує випадкові стінки на порожніх краях поля. До дерева пошуку потрапляють лише ті перегородки, що безпосередньо впливають на актуальну BFS-траєкторію супротивника.
3. **Рання валідація зв'язності**:
   * Стінки, що перетинають інші або повністю закривають шлях, відсікаються ще до генерації станів у дереві рішень.
